# 지안이의 눈빛정원 · v1.0.1

배움정원의 크림색 배경, 파스텔 카드, 꽃과 구름, 기존 캐릭터 리소스를 활용한 어린이 가정용 시력 참고 웹앱입니다. iPhone 16 Pro의 세로 화면과 Safari 사용을 우선으로 설계했습니다.

**임상 검증을 거친 의료기기가 아닙니다.** 안과 시력검사, 굴절검사, 안경 도수 결정, 근시·난시·약시 진단 또는 배제에 사용할 수 없습니다. 실제 아이폰 기기와 임상 검사의 비교 검증은 수행하지 않았습니다.

## 사용 순서

1. 실제 자를 준비하고 화면의 양 끝 눈금 사이를 5cm로 맞춥니다. 기기 이름이나 CSS의 `mm` 단위만으로 실제 크기를 가정하지 않습니다.
2. 화면부터 아이의 눈까지 **정확히 3m**를 잽니다. 10피트(3.048m)와 혼용하지 않습니다.
3. 휴대폰을 눈높이에 고정하고 반사 없는 밝은 실내에서 사용합니다. 화면 밝기는 보호자가 수동으로 조절합니다.
4. 안경 착용 여부를 선택하고 E의 열린 방향을 연습합니다.
5. 왼눈을 누르지 않고 가린 뒤 오른눈을 검사하고, 눈을 바꿔 검사합니다. 아이는 제자리에 머물고 보호자가 정답을 입력합니다.
6. 두 눈을 모두 마치면 통과 단계와 검사 조건을 기기에 기록합니다. 결과 JSON을 파일로 내보낼 수 있습니다.

새로고침 또는 중단 시 진행 중인 검사는 저장하지 않습니다. 화면 크기, 방향, 브라우저 확대가 달라지면 검사를 중단하고 재보정합니다. 매 검사마다 자로 확인합니다. 검사 중단은 결과를 남기지 않습니다.

## 검사 방식과 한계

- 3m에서 소수시력 1.0에 해당하는 기호 전체 높이를 5분각으로 계산합니다. `height = 2 × 3000 × tan((5 / 단계) × π / 10800 / 2)` mm.
- 일반 글꼴 대신 5×5 격자의 E 기호를 SVG로 그립니다. 획과 간격은 기호 높이의 1/5입니다.
- 4방향 무작위, 한 단계 5문항 중 4개 이상 정답일 때 다음 단계로 이동합니다. 처음 실패한 단계에서 해당 눈 검사를 마칩니다.
- 단계: 0.2, 0.25, 0.32, 0.4, 0.5, 0.63, 0.8, 1.0, 1.25, 1.5.
- 주변 기호 영향 감소를 피하고자 E 주변 네 면에 막대를 표시합니다. 이 막대 배치와 판정 알고리즘은 임상 검증을 받지 않았습니다.
- 0.1 단계는 3m에서 주변 막대까지 포함하면 세로 휴대폰의 폭을 넘기므로 제공하지 않습니다. 가장 큰 0.2 단계도 보정 후 화면에 들어가지 않으면 시작을 막습니다. 크기를 줄여 억지로 맞추지 않습니다.
- 결과는 **통과한 단계**이며, 확정 시력이 아닙니다. 0.2 미통과 시 실제 시력이 0.2 미만이라고 단정할 수 없고, 1.5 통과 시 그 이상의 시력을 확인한 것이 아닙니다.
- 표준화된 전체 시력표, logMAR 문항 점수 방식, 조명 측정, 자동 거리 측정, 조절마비 굴절검사 기능은 없습니다.
- 좌우 차이·반복적인 어려움·찡그림 등 우려가 있으면 점수와 관계없이 안과에서 확인합니다.

설계 참고: [AAPOS 검사 도구](https://www.aapos.org/public/resources/screening-kits-patients), [AAPOS 시력 선별검사](https://www.aapos.org/syndicated/vision-screening), [Apple iPhone 16 Pro 사양](https://support.apple.com/en-sg/121031). AAPOS의 10피트 검사 도구를 이 앱이 그대로 구현하거나 인증받았다는 뜻은 아닙니다.

## 데이터와 오프라인

- 계정·서버·외부 API·분석 추적 없이 작동합니다. 이름·생년월일을 수집하지 않습니다.
- 결과와 화면 보정은 이 기기, 이 사이트, 이 브라우저의 `localStorage`에 저장합니다. 자동 동기화하지 않습니다. Safari와 설치한 홈 화면 앱은 기록이 다를 수 있습니다.
- 최대 최근 300개 검사만 유지합니다. 이전 기록이 중요하면 JSON을 내보내 보관하세요.
- 브라우저 저장이 실패하면 안내하고 결과 내보내기를 제공합니다. 저장소 삭제 시 기록도 삭제될 수 있습니다.
- 서비스 워커가 전체 필수 파일을 받은 뒤 오프라인 준비 완료를 표시합니다. 처음에는 HTTPS에서 온라인으로 열어야 합니다.
- 업데이트는 사용 안내의 ‘새 버전 적용’에서 실행하며, 검사 중에는 적용을 막습니다. 앱 업데이트는 검사 기록을 지우지 않습니다.
- 검사 화면은 흰 배경·검은 기호를 유지합니다. 다크모드·기호 색상 변경은 제공하지 않습니다.

## GitHub Pages 배포

별도 빌드와 의존성 설치 없이 저장소 루트의 파일로 작동합니다.

1. GitHub 저장소 → **Settings → Pages**.
2. **Build and deployment → Source → Deploy from a branch**.
3. **Branch: main**, **Folder: / (root)**를 선택하고 Save.
4. 배포 성공 후 `https://phone73-cmd.github.io/kids-vision-check/`로 접속합니다. 이 주소는 Pages 설정이 완료되어야 열립니다.

기존 저장소 공개 범위를 변경하지 않습니다. 비공개 저장소의 Pages 사용 가능 여부는 GitHub 요금제·계정 정책에 따라 다릅니다.

## 개발 및 검증

```sh
npm test
node --check app.js
node --check sw.js
```

Node 내장 테스트만 사용하므로 `npm install`은 필요하지 않습니다. 기호 물리 크기 계산, 보정 비율, 5문항 판정, 하한·상한 결과, 회전 기호를 검사합니다.

파일: `index.html`, `styles.css`, `app.js`(화면·저장), `vision.js`(기호·계산), `sw.js`(오프라인), `manifest.webmanifest`, `assets/`.

현재 검증 범위: 계산 단위 테스트와 코드 구문 및 파일 참조 검사. 자동 브라우저 QA는 실행 환경의 접근 정책으로 수행하지 못했습니다. 실제 iPhone 16 Pro에서 자 보정, 3m 양안 검사, Safari·홈 화면 실행, 오프라인 상태, JSON 다운로드 확인이 필요합니다.

## 리소스

꽃·캐릭터·하늘 리소스는 같은 소유자의 [multiplication-garden](https://github.com/phone73-cmd/multiplication-garden) 저장소에서 재사용했습니다. Gowun Dodum에서 앱에 필요한 글자를 추린 EyeGardenSubset 폰트의 OFL 라이선스는 `assets/fonts/Gowun-Dodum-OFL.txt`에 포함했습니다. 앱 아이콘은 이 저장소의 SVG입니다.
